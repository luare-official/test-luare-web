# C-06｜料金PDF請求フォーム：個人情報・同意設計草案（未承認）
2026-10-23／C班／初回レビュー用。**法務判断・ユーザー承認前のため、公開サイトへ反映しない。** 個別企業の情報・実顧客データは含めない。

## 前提（決定済み）
- 申込者がフォームへ入力したメールアドレス宛に、承認済み料金PDFを**本人確認なしで1通**送信。受付画面からPDF直接配布は行わない。
- PDF内容・価格、差出人、配信事業者の契約、保存先、プライバシー文面は未確定。本人確認用のトークン・追加メールは不要。
- メールアドレスの保有者を検証しないため、誤入力や第三者入力による不意のPDF送付は排除できない。フォームで再確認を促し、Bot対策・配信制限・誤送信の通報受付を実施。

## 収集項目と利用目的の案
| 項目 | 収集 | 利用目的 |
| --- | --- | --- |
| 会社名 | 必須 | 法人向けサービスの資料請求の管理・対応 |
| お名前 | 必須 | 問い合わせ対象の識別、返信時の宛名 |
| メールアドレス | 必須 | PDF資料の配信および送信不能の対応 |
| ご関心のサービス | 任意 | 希望に沿った資料の選定・問い合わせ対応（正式な資料区分は後日決定） |
| ご相談内容 | 任意 | 本人が記入した内容への問い合わせ対応 |
| 同意日時・同意ポリシー版 | システム記録案 | 同意の記録とトラブル対応 |
| 配信結果／申込識別子 | 必要最小限のシステム記録案 | 重複配信防止・送達事故対応 |
| IP・ブラウザー情報 | 原則長期保存しない | 不正送信のレート制限に必要な範囲のみ短期・最小化 |

**本人確認不要**と**個人情報取得・利用目的の説明不要**は別問題。資料送付以外の継続的な営業メールやメルマガは自動登録しない。資料請求への応答メールの後のマーケティングを希望するなら、別途任意選択欄の設計・承認が必要。

## フォームに表示する同意文面（案・未承認）
> お客様情報は、料金・サービス資料の送付と、ご依頼いただいた内容への対応のために利用します。［プライバシーポリシー］を確認し、個人情報の取扱いに同意します。

- 「［プライバシーポリシー］」は、正式に承認された実URLへ差し替え、それまでは公開不可。
- 同意チェックはデフォルト**未選択**、必須。必要に応じてリンクを新しいタブで開けるようにする。
- 同意ログは原文を無期限に複製せず、ポリシー版・日時等の必要最小限を記録する。

## 保存・第三者提供・国外委託（決裁事項）
- **削除期間（案）**：未対応・失敗記録は一定期間後に削除、通常の請求データは「90日」を試案とする。これは法律上の一律期間を意味せず、実際の法的保存義務・営業運用・契約条件を確認して決定する。問い合わせが進行する場合は別管理規程を検討。
- Cloudflare/Resend等の処理先・所在地・越境移転に関する要件、委託契約、サブプロセッサ、削除・保存範囲を本契約前に確認。未確認の国名やサーバ所在地を「国内」と断定しない。
- メール配信ログ・エラーログに氏名、本文、PDF、APIキーを残さない。問い合わせ文中には秘密情報を送らないよう注意喚起。
- 管理画面アクセスは担当者に限定し、権限変更・異常送信停止・削除依頼窓口・漏えい時の初動を文書化する。
- Web解析（GA等）には氏名・メール・問い合わせ本文・URL内の個人情報を渡さない。
- 配信メールの添付ファイルは受信者側で転送できる。公開PDFリンクを設けないだけでは転送制限にならない。
