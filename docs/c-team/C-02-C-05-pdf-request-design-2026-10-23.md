# C-02 / C-05｜料金資料請求・PDF自動送付仕様 v0.3（2026年10月23日）

## 正式な送信方式（最新のユーザー決定）
**本人確認は行わない。申込受付後、フォームで入力されたメールアドレス宛にPDF添付メールを原則1通送信する。受付完了画面では送付状況を案内し、PDFの直接ダウンロードは設けない。**

- 2026年10月23日に一度選ばれた「A案：メール認証→PDF添付メール＋認証画面ダウンロード」は、同日のユーザー指示で**取り消し**。本v0.3がv0.2より優先する。
- メール認証用の1通目、確認リンク、認証トークン、一時ダウンロード権限、認証画面のPDFダウンロードは不要。
- 方式の決定は、実送信機能・料金額・PDF本文・個人情報文面・送信事業者の承認とは別。**未承認の間は外部配信を停止**する。
- 料金額や夫のr5原案の金額は、一般公開サイト・GitHubの公開ソース・管理表に載せない。

## C-02｜お客様の流れ
1. トップ/サービス詳細から専用の料金資料請求ページ（仮URL：`/pricing-request`）へ移る。ユーザーが承認したHTMLをデザイン正本とする。
2. 会社名（必須・100字以内）、お名前（必須・80字以内）、メールアドレス（必須・254字以内）を入力。関心のあるサービス・ご相談内容（上限1,000字）は任意。
3. 資料送付に必要な個人情報の利用目的とポリシーを確認し、必須同意をチェックする。営業メールへの同意は別目的・任意として、承認がない限り追加しない。
4. 「このメールアドレスへ資料を送ります」と入力値を目立つ位置に表示して誤記を見直せるようにする。認証・認証コード入力・会員登録・パスワード設定・アドレス二重入力は要求しない。
5. お客様が「資料をメールで受け取る」を押す。フォームの必須/形式/長さをブラウザとサーバーの双方で検証し、送信中の二重押しを抑止する。
6. サーバーが安全条件・PDF承認版・メール配信設定を確認して、入力アドレス宛に**承認済み料金PDFを添付した1通**を送信する。
7. 画面は「お申し込みを受け付けました。メールをご確認ください」と案内（送信未成功なのに「送信済み」と断言しない）。未着時の迷惑メール確認/お問い合わせを表示し、**画面でPDFは配布しない**。

### 予想される手間と制約
- お客様の通常操作はフォーム入力のみ。本人確認メールは届かない。原則PDF添付メール1通。
- アドレスの打ち間違い自体は検証できない。画面での再確認、メール構文チェック、Typoによる一般的なドメイン誤記の注意喚起を検討。
- 他人のアドレスを入力される迷惑送信リスクと、その宛先へのPDF誤配送は**本人確認なしでは完全に防げない**。大量の迷惑送信はCAPTCHA、回数制限、送信頻度制御、監視で抑制する。
- 本人確認ありでも、受領したPDFの転送、競合企業の正規請求は防げない。

## C-04｜画面デザイン・アクセシビリティ
- 一列のスマホレイアウト、読みやすいラベル、タップしやすいボタン、画面幅360px/390px以上の検証。
- `label`と`id`の対応、入力補助、バリデーションエラーとフォーカス、画面読み上げ、キーボード操作、二重送信抑止。
- 個人情報をURLクエリ・解析イベント・画面キャプチャに残さない。入力済みメールの確認はフォーム操作中のみに表示。
- 送信前表示の正確な文面と個人情報同意文面はC-06/C-07にて別途確認。

## C-05｜推奨する安全な送信構成（未契約・未実装）
```text
[GitHub Pages / Next.js静的な資料請求フォーム]
  └ HTTPS POST（サーバー側に設ける申込API）
      └ [Cloudflare Workers]
            ├ Turnstile Siteverify / 入力検証 / 送信頻度制限
            ├ 申込単位の冪等性・配信記録（D1等）
            ├ private Cloudflare R2：承認済みの料金PDFのみ
            └ Resend：**フォーム入力アドレスへPDF添付メール1通**
      └ [ブラウザの受付完了画面] PDFのWebダウンロードなし
```
- **秘密情報分離**：Resendキー、Turnstileキー、PDF実体、D1データを公開GitHub、`NEXT_PUBLIC_*`、HTML、ブラウザJSやActionsログに含めない。Workers Secrets・private R2を利用。
- **配信開始の安全ゲート**：初期は`SEND_ENABLED=false`。テスト時だけ`TEST_MODE=true`かつユーザー決裁済みのテスト専用宛先allowlistに一致した場合に限る。一般顧客・営業先には試験送信しない。
- 送信元ドメインのDNS SPF/DKIM/DMARCを設定し、Reply-To・件名・メール文面を承認してから有効化する。
- Turnstileの検証はサーバー側で必須。IP等を不必要に保存せず、スパム対策のレート制限・連投検出を行う。Origin/CORS設定を本人確認の代替とはみなさない。
- 同一申込IDの二重送信、再読込、タイムアウト再試行時の再送事故を防止。問い合わせの本文を送信サービスのログに不必要に残さない。
- PDFは版管理を行い、承認済みの最新版のみ送付する。添付ファイルの最大容量と送達性をテストする。
- 資料送付と後日のマーケティング連絡は区別し、メール開封追跡は当初無効とする。

## 異常系
| 条件 | 安全な処理 |
| --- | --- |
| メール形式不正・必須同意なし | 送信せず入力修正を案内 |
| Bot/短時間の大量申込 | サーバー側で止める。回数制限と防御の検証 |
| 同一申込の二重実行 | 冪等性で原則1通以下にする |
| PDF未承認、期限切れ、保管先不明 | fail closedで送付停止 |
| メールAPIキー/設定なし | 送付停止、管理者に対応依頼 |
| メールAPI障害・タイムアウト | 配信状態とIDを確認し、重複を抑えて再試行 |
| アドレスの存在を検証できない | 本人確認なしの制約として認識し、フォーム内でアドレス再確認を促す |
| PDF添付サイズ超過 | 送信停止・資料の最適化を検討。恒久的な公開PDF URLへの自動切替なし |

## 費用の概算・1通方式への変更点（2026-10-23時点）
| サービス | 無料枠・目安 | 有料時の目安 |
| --- | --- | --- |
| Cloudflare Workers | Free $0（月額）、利用回数・CPUに無料上限あり | Paid 最低$5/月 |
| Cloudflare R2 | Free 10GB-month等 | 保管/操作量に応じ従量 |
| Cloudflare D1 | Free枠あり（冪等性・配信状況用） | 従量条件あり |
| Cloudflare Turnstile | Freeプランあり | Enterprise等は別条件 |
| Resend | Free $0、**月3,000通・1日100通** | Pro $20/月、月50,000通の目安 |
| 開発/保守/DNS・ドメイン | 無料枠に含まれない | 実際の作業・契約に依存 |

- 1申込につき通常**1通**：月30件→30通、月100件→100通、月1,000件→1,000通。本人確認ありの旧方式より原則半減。Resend無料枠は**月と日の両方**を満たす必要があり、通知メール等も送信通数に含まれる。
- 少量なら外部サービス費**月額$0の可能性**はあるが確約ではない。PDFサイズ、利用量、税、為替、初期構築・保守、送信失敗時の運用工数は別。
- 料金公式： https://developers.cloudflare.com/workers/platform/pricing/ 、https://developers.cloudflare.com/r2/pricing/ 、https://developers.cloudflare.com/d1/platform/pricing/ 、https://resend.com/pricing 、https://developers.cloudflare.com/turnstile/plans/ 。導入時に適用条件を再確認する。
